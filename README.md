# Cherryfields umbrel apps

Community app store for umbrelOS. Add this repo's URL under App Store → ⋯ → Community App Stores.

- `cherryfields-couchdb` — CouchDB 3.4 configured for Obsidian Self-hosted LiveSync.
- `cherryfields-dagu`: Dagu 2.19, cron jobs and scripts with a web UI (basic auth `admin` / umbrel app password).
- `cherryfields-metadata-remote`: Metadata Remote 1.2.0, web-based audio tag editor.
